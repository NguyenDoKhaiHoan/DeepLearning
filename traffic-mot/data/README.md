# Dữ liệu đầu vào

Chưa cung cấp VisDrone MOT trong dự án mới. Không dùng VisDrone2019-DET
làm ground truth tracking. Phase 5 sẽ xác thực ID theo thời gian, class,
ignore regions, truncation/occlusion và split theo sequence trước khi đánh giá.

Dataset nằm ngoài Git; cấu hình đường dẫn qua YAML hoặc CLI khi runtime được triển khai.
